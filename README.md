# Telco Customer Churn — Multi-Model Classification & Streamlit Demo

## a. Problem Statement
Customer churn — when a subscriber stops using a company's service — is one
of the most expensive problems in the telecom industry, since acquiring a
new customer typically costs far more than retaining an existing one. This
project builds and compares six classification models that predict whether
a telecom customer will churn (`Yes`/`No`) based on their account and
service usage attributes, so that a business could proactively target
at-risk customers with retention offers.

## b. Dataset Description
- **Source:** Telco Customer Churn dataset (Kaggle, originally published by
  IBM Sample Data Sets).
- **Instances:** ~7,043 customer records.
- **Features:** 19 predictor columns spanning demographics (gender, senior
  citizen status, partner/dependents), account information (tenure,
  contract type, payment method, billing), and subscribed services
  (phone, internet, streaming, security, backup, tech support add-ons).
- **Target:** `Churn` — binary (`Yes` / `No`).
- **Class balance:** ~26.5% churn / ~73.5% no-churn (moderately imbalanced —
  this is why MCC is reported alongside Accuracy).
- **Preprocessing:** dropped `customerID`; coerced `TotalCharges` to
  numeric (a handful of blank strings for new customers with 0 tenure were
  imputed with the median); numeric features scaled with `StandardScaler`;
  categorical features one-hot encoded.

### Observations

| ML Model Name | Observation about model performance |
|---|---|
| Logistic Regression | Best overall model on this dataset — highest Accuracy (0.8055), highest AUC (0.8419), and highest MCC (0.4790). Its precision and recall are reasonably balanced, suggesting the churn signal in this dataset is largely linear/monotonic in features like tenure, contract type, and monthly charges, which suits a linear decision boundary well. |
| Decision Tree | Weakest model across almost every metric (lowest AUC at 0.6573, lowest MCC at 0.3119). A single unpruned tree overfits to noise in the training split and generalizes poorly — it captures fewer of the broader trends that the ensemble and linear models pick up. |
| kNN | Middle-of-the-pack performer. AUC (0.8050) is close to Logistic Regression, but Accuracy and MCC trail behind, likely because distance-based similarity is diluted by the large number of one-hot encoded categorical features (curse of dimensionality), even after scaling the numeric columns. |
| Naive Bayes | Lowest Accuracy (0.6948) and lowest Precision (0.4589), but by far the highest Recall (0.8369) — it catches almost all actual churners, at the cost of many false positives. This is a direct consequence of its conditional-independence assumption not holding for correlated churn drivers (e.g., Contract type and tenure), which biases it toward predicting the minority "Yes" class more aggressively. |
| Random Forest (Ensemble) | Second-best on Accuracy (0.7779) and AUC (0.8173), but its Recall (0.4706) is the lowest of all models — it favors precision over catching every churner. Averaging many trees clearly fixes the single Decision Tree's overfitting problem, but the model still leans conservative on flagging churn. |
| **Overall Winner for your dataset?** | **Logistic Regression** — it has the best Accuracy, AUC, and MCC (the most robust metric given the ~27% churn class imbalance), while keeping Precision and Recall reasonably balanced. In a real retention-campaign setting, Naive Bayes could be a deliberate alternative if the business cost of missing a churner is much higher than the cost of a false alarm (e.g., a cheap retention email), since it maximizes Recall. |

## How to Reproduce
```bash
pip install -r requirements.txt
python train_models.py --data telco_customer_churn.csv
streamlit run app.py
```

## Streamlit App Features
- CSV upload for test data
- Model selection dropdown (all 5 algorithm families, 6 total counting the
  ensemble as separate from its base learners per the assignment spec)
- Live evaluation metrics (Accuracy, AUC, Precision, Recall, F1, MCC)
- Confusion matrix heatmap and full classification report
